# AI 价格核验日期自动过期修复（2026-11-04）

产品决策：价格核验日期仅作为审计信息，不按7天自动停用；不采用修改未来日期的变通，不新增人工定期核验流程。

实现：server/quiz-core.mjs移除日期解析及有效期拦截。保留服务商/模型价格匹配、正数价格、金额预留、持久化账本、幂等及失败不退还请求预留。原1000累计、300每日、单来源60每日与10每分钟限制不变；Worker配置中的核验日期不修改。

前端：关闭/配置不可用、预算存储异常、模型异常和限速不显示为额度耗尽。仅budget_exhausted显示调用额度已用完；这是应用请求/预留额度，不等同于供应商Token余额。模型错误不擅自猜测为免费Token耗尽。

费用边界：负责人于本轮亲自在百炼控制台确认qwen-flash免费额度仍有效且用完即停开启。配置与估算预留不能替代供应商账单保护，价格变更仍可能影响预留估算。未增预算、未更改供应商收费设置。

验证：使用Mock模型和SQLite测试旧日期、空日期、无效日期不影响可用性且仍扣减请求预留；继续验证累计/每日/来源频率、金额、并发及故障关闭保护；增加前端不同错误提示与网络失败不重试测试。全部验证结果及实际部署状态在本次交付报告中列明，模拟测试不代表真人完整游戏验收。
