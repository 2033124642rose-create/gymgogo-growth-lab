# V2 统一开局与新手引导（本地待真人验收）

## 目标和依据
基线仅用于探索性定位，不能宣称V2已提升转化。负责人提出：单人入口难找、首次不知玩法、动作不计数、摄像头隐私顾虑与步骤繁琐。本批只开发对应体验，不开展实验。

## 实施与功能边界
- V1默认分支仍保留全部原流程，生产基线提交795941e可追溯；不覆写或重写历史。
- src/v2/experience.ts集中选择体验；仅DEV下?experience=v2启用。生产构建始终默认V1，不提供公网绕过入口。
- 首页只保留一个醒目的立即开始，打开明确单人/多人选项；选择单人后自动prepare，再主动开启摄像头，保持真实检测和倒计时，未就位不进入active。多人仍需昵称/帽子设置和当前玩家准备，不替队友自动开局。
- 首次三步教程支持跳过和Escape，记住本机选择；存储失败时只保证本次关闭，下次可能重现。教程不申请摄像头。AI题目明确仅限启用AI的派对模式。
- 摄像头授权前显示视频/图像不上传说明。已核对CameraController、pose-worker仅通过本地postMessage传递图像帧。匿名行为统计功能保留。
- V2摄像头加入站位和完整动作提示，复用原游戏的下蹲、请起立和成功+1反馈；SquatCounter与ReadyGate不改，不为转化放宽动作规则。本轮未定位到可复现的底层计数Bug；用户不计数反馈仍需真人站位/光线与动作复测，不能宣称完全解决。
